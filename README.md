# Mój portfel

## Uruchomienie lokalnie
npm install
npm run dev

## Budowanie produkcyjne
npm run build
# wynik trafia do folderu dist/ - wgraj go na dowolny hosting statyczny

## Wdrożenie (najprościej)
- Netlify / Vercel: połącz repo albo przeciągnij folder dist/ po zbudowaniu
- Dane portfela zapisują się w localStorage przeglądarki (per urządzenie/przeglądarka)
- Klucz API Twelve Data ustawiasz w aplikacji: Ustawienia -> Klucz API Twelve Data
